# gestaltdb-examples

Example projects using [GestaltDB](https://github.com/mylonasc/gestaltdb).

## Examples

- **[yago45-kge/](yago45-kge/)** — YAGO 4.5 knowledge-graph embeddings: ingest YAGO
  into GestaltDB, serve micro-batches from a CSR sampler snapshot, encode with a
  compiled [tf_gnns](https://github.com/mylonasc/tf_gnns) message-passing network,
  and train 200-dimensional entity/relation embeddings with contrastive loss.
